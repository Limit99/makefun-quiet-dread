# LGTM, Eventually

A tiny Node/TypeScript program for the make.fun bounty "Two Days of Quiet Dread". It writes one approving code-review comment carrying quiet existential dread to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 140 characters.

Entry line:

> LGTM. The logic is sound, the tests pass, and the merge button is right there waiting, the same way every door is waiting, eventually.

Run it with: `node main.ts`
